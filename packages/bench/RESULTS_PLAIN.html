Method, bootstrap intervals and limitations

All times include in-page websocket protocol work, fake-server query evaluation, JSON and task scheduling. No network or real backend. Sparse updates still evaluate the entire query set on the fake server. Mutation/page UI rows use fixed-size fixtures at N=1000.

Both plain columns use the same React component, keyed DOM and useSyncExternalStore. The native facade owns its frame and reads public result atoms, without any compatibility classes. React is production, not profiling.

The interval is a paired bootstrap 95% interval for the ratio of medians, native/PR. It does not quantify variation across machines. Differences below 10% or times below 0.3 ms can be noise. p95 is descriptive from 25 samples, not a service-level guarantee.

Native facade integration checks: 10 groups passed. SSR, Suspense, auth provider components, preloading, and full legacy API parity are not provided by this prototype. Auth/reconnect performance and long-lived leak tests were not run.
